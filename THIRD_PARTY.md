# Third-party components

QuizVerse uses unmodified, dynamically loaded packages. Its MIT license covers
only QuizVerse's own source and original assets.

- **Python 3.12** — Python Software Foundation license; [Python licensing](https://docs.python.org/3/license.html).
- **PySide6 / Shiboken6 / Qt 6.8.3** — The Qt Company and contributors; available under LGPL/GPL/commercial licensing. This project uses Qt Core, GUI, Widgets, SVG support, and Multimedia through the community wheels. See the installed wheels' `*.dist-info` and `PySide6` license files and [Qt for Python licensing](https://doc.qt.io/qtforpython-6/licenses.html).
- **SQLite** — public domain, supplied through Python's standard library; [SQLite copyright](https://www.sqlite.org/copyright.html).
- **PyInstaller** — build tool with a bootloader distribution exception; see its installed license and [PyInstaller licensing](https://pyinstaller.org/en/stable/license.html).

Preserve dependency license notices with distributed builds. The folder build
keeps Qt shared libraries outside the executable. No third-party photographs,
icon packs, recordings, web fonts, or remote assets are used. Icons are original
SVG/vector drawings and audio is generated by `tools/build_assets.py`.
